Databricks on AWS: step-by-step guide

This guide takes you from nothing to a running Databricks job, one step at a time. Each step says, in plain words, what it is for, what you give it, what you do, and what it creates. The animation in each step shows the resources appearing in the order they are created.

Two GitHub repos do the work: databricks-platform builds the AWS network, the Databricks workspace and each team; databricks-jobs puts a team's jobs into that workspace. You set up int now; qa is the same later.

01The 14 steps

Steps 1-5 are done by hand once. Steps 6-10 run by themselves in GitHub after you push the platform repo. Steps 11-14 set up the jobs repo and run the first job. Click a box to jump to it, or take the tour: it scrolls through every step and plays its animation.

TOnboard another team

Once the platform is running, a new team needs one file and one pull request. Example: team fin with its own jobs repo.

QAdd qa later

  1. Bootstrap qa (like step 2) with bootstrap/qa.tfvars. If qa uses the same AWS account as int, set create_github_oidc_provider = false and run terraform workspace new qa first.
  2. Platform repo > Settings > Environments > qa: the same 3 variables (qa values) and 2 secrets as step 4. Add Required reviewers and limit it to the main branch.
  3. Fill in config/qa.yaml (like step 5). Add qa to each ready team: environments: [int, qa].
  4. Actions > platform-deploy > Run workflow: environment qa, stacks all. A reviewer approves the run. Steps 7-10 happen for qa.
  5. Jobs repo: environment qa with the qa hand-off variables, then Actions > jobs-deploy > Run workflow > qa.

XTear int down

int is for testing, so its config allows deleting data. Do it in this order:

  1. Jobs repo: Actions > jobs-destroy, environment int, type int to confirm. Removes the job and notebooks.
  2. Platform repo: Actions > platform-destroy, environment int, stacks all, type int. Removes step 9, then step 8, then step 7.
  3. Optional: terraform destroy -var-file=int.tfvars in bootstrap/. The state bucket is protected; remove prevent_destroy first if you really want it gone.

!Troubleshooting

MessageWhat it means and the fix
The GitHub environment is missing: ...A variable or secret is not set on the environment. Add it under Settings > Environments (steps 4 and 11).
Not authorized to perform sts:AssumeRoleWithWebIdentityAWS does not recognise the repo. The org/repo name or its upper/lower case differs from step 2 (platform) or from job_repos (jobs), or the environment is not called int.
AWS credentials are for account X, but config says YSafety stop: wrong AWS_ROLE_ARN or wrong aws.account_id.
has unknown keys / Team files have problems / Job files have problemsA misspelled key in a YAML file. The message names the file and the key.
Databricks 401 / invalid_clientWrong or expired OAuth secret. Make a new one (step 3) and update the GitHub secret.
PERMISSION_DENIED ... CREATE CATALOG / STORAGE CREDENTIALThe CI service principal is not a metastore admin (step 3, part 4).
Metastore assignment fails: workspace already assignedDatabricks attached the workspace by itself. Set unity_catalog.assign_metastore: false and re-run.
databricks_metastore not foundNo metastore in the region: set create_metastore: true or metastore_id.
user ... not foundAn e-mail in a file is not a user in the Databricks account. Add or sync the user, or create_users: true in a sandbox.
Storage credential / external location validation failsAWS had not finished saving the new role. Re-run the workflow.
wait until the workspace answers: timed outRe-run. If an IP allow list or PrivateLink without public access is on, GitHub's runners cannot reach the workspace.
Validation failed for node_type_id / num_workersThe job asks for a machine type or size the team's policy does not allow.
cluster policy <team>-job-policy not foundThe team does not exist in this environment yet, or the TEAM variable is wrong.
secret ... scheduled for deletion (qa)aws secretsmanager restore-secret --secret-id ... or wait 7 days.
Budget creation failsSet budget.monthly_usd: 0.
